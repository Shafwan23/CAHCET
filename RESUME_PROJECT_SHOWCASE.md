The institution required a massive digital overhaul. **The Result:**
A highly scalable, secure, and performant platform that completely digitized the institution's operations, reduced administrative bottlenecks, and modernized their public digital presence.

## 6. Technical Achievement Highlights

*   **Architecture:** Designed a decoupled client-server architecture separating the React frontend from the Node/Express API, allowing for independent scaling and maintenance.
*   **Database Design:** Engineered a normalized PostgreSQL database schema using Prisma. Handled complex One-to-Many relationships (Users to Departments, Applicants to Applications) while enforcing referential integrity.
*   **CMS Development:** Built a custom version-controlled CMS from scratch. Implemented additive database fields (`draftContent`, `isVisible`) to support safe editing workflows without mutating live data.
*   **RBAC & Security:** Implemented a multi-tiered authorization system. Middleware actively decodes JWTs, checks the user's role against a permissions matrix, and blocks unauthorized access to specific API routes and UI components.
*   **Authentication:** Developed a secure, stateless JWT authentication flow. Implemented bcrypt for cryptographic password hashing and utilized Helmet/CORS for Express security hardening.
*   **Admissions Portal:** Created a stateful, multi-step application pipeline. Engineered the database to handle flexible JSON data payloads for academic and personal details while maintaining strict tracking statuses.
*   **Performance Optimization:** Achieved sub-second load times using Vite's optimized build process, lazy-loading React components, and efficient Prisma query batching.
