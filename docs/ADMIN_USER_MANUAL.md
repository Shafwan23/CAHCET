# Admin User Manual

Welcome to the CAHCET Content Management System.

## Logging In
1. Navigate to `www.cahcet.in/admin/login`.
2. Enter your authorized college email and password.

## Navigating the Dashboard
Once logged in, you will see the **Overview Dashboard**. The left sidebar contains all the CMS modules categorized by department:
- **Homepage:** Manage the hero video, stats, and gallery.
- **About:** Manage institutional policies, messages, and history.
- **Departments:** Update curriculum, faculty lists, and galleries for specific branches.
- **Updates:** Post the latest news, announcements, and events.

## The Draft → Review → Publish Workflow
We use a strict publishing workflow to prevent mistakes on the public website.
1. **Editing:** Make changes in any editor. Click **Save Draft**. This saves your work, but *does not* put it on the public website.
2. **Reviewing:** Click **Live Preview** to see exactly how your draft will look on the real website.
3. **Publishing:** Once approved, click **Publish**. This immediately updates the public-facing website.

## User Management
If you have `SUPER_ADMIN` rights, you can click "Users" in the sidebar to add new faculty accounts and assign them `EDITOR` or `ADMIN` roles.
