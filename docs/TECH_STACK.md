# Tech Stack

## Programming Languages
- **JavaScript (ES6+)**: Used across the entire stack for unified development context.

## Frontend
- **React 18:** Chosen for its component-based architecture and dominant ecosystem.
- **Vite:** Chosen over Webpack/CRA for ultra-fast HMR and highly optimized Rollup builds.
- **Tailwind CSS:** Utility-first CSS framework for rapid UI development and ensuring consistent design tokens without bloat.
- **Framer Motion:** Chosen to handle complex layout transitions and micro-animations easily.
- **React Router DOM v6:** For robust Single Page Application routing.

## Backend
- **Node.js & Express.js:** Lightweight, non-blocking asynchronous backend serving JSON REST APIs.
- **Prisma ORM:** Chosen for incredible developer experience, type-safety, and seamless database migrations.
- **PostgreSQL:** Reliable, enterprise-grade relational database for managing structured data and JSONB payloads.

## Security & Deployment
- **JWT (jsonwebtoken) & bcrypt:** For secure authentication mechanisms.
- **Render:** Cloud PaaS chosen for zero-config CI/CD deployments of both static sites and web services.
